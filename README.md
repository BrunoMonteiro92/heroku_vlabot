## Sobre

Vlad Bot é um **Telegram Bot** ultra-sensacional, agora **rodando em Node.js + TypeScript**, com:

- Comentários épicos que enriquecem qualquer conversa
- Fotos e áudios que enlouquecem a galera
- Respostas sinceras para perguntas sinceras
- E, claro, muita calma e risadas pelo caminho 😎

---

## Comandos

```bash
/vlad      - Comentários ultra-enriquecedores
/askvlad   - Respostas honestas para qualquer pergunta
/fera      - Fotos sensuais que enlouquecem a galera
/calma     - CALMA SENHORA, respira fundo
/diz       - Ouça a voz inconfundível de Vlad
```
